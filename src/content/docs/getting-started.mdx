<Aside>
  Make sure to add your domain in the
  [dashboard](https://app.corsfix.com/applications) to use Corsfix on live
  websites. <br />
  For local websites (localhost), you can use Corsfix without any setup.
</Aside>

To use Corsfix, add `https://proxy.corsfix.com/?` before your URL when making fetch requests.

```javascript
// Add Corsfix URL before the API
// https://proxy.corsfix.com/? + https://api.example.com/data

fetch("https://proxy.corsfix.com/?https://api.example.com/data");
```

## Basic Usage

```javascript
// GET request
fetch("https://proxy.corsfix.com/?https://api.example.com/users")
  .then((response) => response.json())
  .then((data) => console.log(data));

// POST request
fetch("https://proxy.corsfix.com/?https://api.example.com/users", {
  method: "POST",
  body: JSON.stringify({ name: "John" }),
  headers: {
    "Content-Type": "application/json",
  },
});
```

## API Key

You should use the domain whitelist via the [dashboard](https://app.corsfix.com/). If that's not possible for your use case, you can fall back to using an API key.

```javascript
fetch("https://proxy.corsfix.com/?https://api.example.com/data", {
  headers: {
    "x-corsfix-key": "cfx_12345678",
  },
});
```

We discourage using API key on the client side, as it can be exposed in your source code and browser network requests.
